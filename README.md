# BS Aim

Screen-capture aim assist overlay for Blood Strike. No root.

## Install
1. Actions tab, run the workflow, download the bsaim-apk artifact.
2. Install the APK (allow unknown sources).
3. Open it, do steps 1-3 in order, then press 4.
4. Launch Blood Strike. Drag the panel by its header.

## Panel
Master, Auto fire tap, Drag mode, Low-spec mode, FOV, Smooth %, Min size, Scan step, Re-arm.

## Game settings
Graphics Low, 30 fps cap, anti-aliasing off, in-game aim assist OFF, close other apps.

## Fixes
- Nothing appears: grant overlay permission, restart.
- Box never lands: raise FOV, lower Min size.
- Taps do nothing: use Drag mode.
- Camera snaps back: raise Smooth.
- Service dies in match: enable battery exemption, reboot.
- Stutter: Low-spec mode on, Scan step 4.
